🗄️ Sobre a disciplina

A disciplina de Banco de Dados aborda conceitos relacionados à criação, organização e manipulação de dados, incluindo:

Modelagem de bancos de dados

Modelo Entidade-Relacionamento (MER)

Modelo Relacional

Criação de tabelas

Relacionamentos entre dados

Consultas SQL

Inserção, alteração e exclusão de dados

Chaves primárias e estrangeiras

Normalização

Desenvolvimento e gerenciamento de bancos de dados
